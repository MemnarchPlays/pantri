How to Set Up Your Discord Bot
  1. Go to discord.com/developers/applications and click New Application
  2. Go to the Bot tab → click Add Bot
  3. Under Privileged Gateway Intents, enable Message Content Intent
  4. Click Reset Token → copy the token → paste it above
  5. Go to OAuth2 → URL Generator, select bot scope and Send Messages / Read Message History permissions
  6. Use the generated URL to invite the bot to your server
  7. For low-stock alerts: right-click the target channel → Copy Channel ID (enable Developer Mode in Discord settings first)
